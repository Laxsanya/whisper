# 🎙️ Whisper AI Speech-to-Text

An AI-powered speech recognition web application that converts uploaded audio files into accurate text transcripts using OpenAI Whisper.

## 🚀 Features

- 🎤 Upload audio files
- 📝 Automatic speech-to-text conversion
- ⚡ Fast transcription
- 🌐 User-friendly web interface
- 📄 Download transcript
- 🎨 Modern responsive UI

## 🛠️ Tech Stack

- Python
- Flask
- OpenAI Whisper
- HTML
- CSS
- JavaScript
- Bootstrap
